# Data Storage

* **Data Storage** = data storage solutions on AWS.
* AWS provides different types of storage, and each type is suitable for different needs.
* When choosing storage, the main factors to consider are:

  * **Performance** → access speed
  * **Cost** → expense
  * **Scalability** → ability to scale

### * Main Types of Storage

* **Block Storage** → like a disk/hard drive, commonly used with EC2.
* **Object Storage** → stores files as objects, for example **Amazon S3**.
* There are also storage solutions for **databases**, **in-memory storage**, and connecting **On-premises** environments to the Cloud.
